This is the repository for my graduate course "The Arithmetic of Elliptic Curves" that I teach (every few years) at UConn. Things that can be found here:

* Lecture notes
* Homework sets
* Apps

More information about the course (including links to the videos by lecture) can be found at the course's website:

https://alozano.clas.uconn.edu/math5020-elliptic-curves/
